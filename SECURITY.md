# Security policy

## Supported versions

The project currently supports the latest version on the main branch.

## Reporting a vulnerability

If you discover a security issue in YumMealPrep, please report it privately and responsibly.

Please use GitHub's private vulnerability reporting:
https://github.com/ASPTechInc/YumMealPrep/security/advisories/new

If private reporting is not available, contact the project maintainer
([@ASPTechInc](https://github.com/ASPTechInc)) through GitHub and ask for a private channel
before sharing any details.

Please do not open a public GitHub issue for security vulnerabilities.

## What to include

When reporting, include:

- a clear description of the vulnerability
- steps to reproduce it
- the affected version or commit
- the platform it affects (Android, iOS, web, Windows, macOS or Linux)
- potential impact
- any suggested mitigation or fix

## Response expectations

We aim to acknowledge valid reports within 5 business days and to provide a
clear remediation plan when possible.

## Disclosure policy

We ask reporters to allow a reasonable time for a fix to be developed and
released before public disclosure. We will coordinate responsibly to avoid
exposing users to unnecessary risk.
